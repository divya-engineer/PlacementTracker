#PLACEMENT TRACKER
A simple web app to track student job applications and placement status

##FEATURES
-Add student details like name,branch,company
-Track application status like applied,rejected,selected
-View all records in a table
-Data stored in browser localstorage(no backend needed)

##TECHNOLOGY USED
-HTML
-CSS
-JavaScript

##HOW TO RUN
1.Open "index.html" in browser
2.Add student details
3.Click "Dashboard" to view all records
